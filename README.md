# Playwright Learning - Python Automation Scripts

A collection of Playwright automation practice scripts written in Python.

## Topics Covered:
- Locators (role, label, placeholder, testid, text, CSS, XPath)
- Assertions (visible, text, value, URL, count)
- Actions (click, fill, hover, drag-and-drop, keyboard input)
- Alerts, Frames, Windows/Tabs
- File Uploads/Downloads
- Shadow DOM
- Dynamic Elements

## PyTest Features:
- Test fixtures (@pytest.fixture)
- Parametrization (@pytest.mark.parametrize)
- Markers (smoke, regression, skip)
- conftest.py (shared fixtures)
- HTML Test Reports (pytest-html)

## Tech Stack:
- Python 3.12
- Playwright 1.61
- pytest 9.1.1
- pytest-html 4.2.0
