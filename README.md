# Playwright Learning - Python Automation Scripts

A collection of Playwright automation practice scripts written in Python.

## Topics Covered:
- Locators (role, label, placeholder, testid, text, CSS)
- Assertions
- Actions (click, fill, hover, drag-and-drop)
- Alerts, Frames, Windows/Tabs
- File Uploads/Downloads
- Shadow DOM
- Dynamic Elements

## Tech Stack:
- Python
- Playwright
- pytest (coming soon)
